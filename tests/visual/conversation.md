## Markdown の表示例

**太字**、*斜体*、`inline code` を含む応答です。

- ユーザーのリクエストを表示します。
- エージェントの応答を Markdown で表示します。

> 入力中の文章は、送信済みの会話とは別に保持します。

| Message | Content |
| --- | --- |
| User | Submitted request |
| Assistant | Completed response |

let greeting = "Hello, Rockstar!";
println!("{greeting}");
